# Update in fünf Schritten

1. Den Inhalt dieses Pakets vollständig in Ihr GitHub-Repository hochladen und vorhandene Dateien ersetzen.
2. Supabase → **SQL Editor** öffnen.
3. `supabase/004_anhaenger_und_sicherer_verlauf.sql` vollständig einfügen und **Run** klicken.
4. In Vercel warten, bis der neueste Eintrag **Ready / Production** zeigt.
5. Die Website öffnen und `Strg + F5` drücken.

Danach können Sie pro Schlüssel oder Schlüsselbund mehrere Anhänger anlegen. Jeder Anhänger hat einen eigenen Text und optional eine eigene Farbe. Ohne Auswahl wird keine Farbe angezeigt.
