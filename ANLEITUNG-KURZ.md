# Kurzanleitung in fünf Schritten

1. **Supabase-Projekt anlegen** und `supabase/schema.sql` im SQL Editor ausführen.
2. **`.env.local`** aus `.env.example` erstellen und die drei Schlüssel eintragen.
3. **Lokal testen:** Abhängigkeiten installieren, dann `npm run dev`.
4. **Ersten Administrator** in Supabase anlegen und per SQL auf `rolle = 'admin'` setzen.
5. **Auf GitHub hochladen** und in Vercel importieren, dort dieselben drei Umgebungsvariablen setzen.

Details stehen in der `README.md`.
